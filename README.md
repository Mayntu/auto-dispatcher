# Автодиспетчер — MVP (фаза 0)

Консультативная система поддержки решений поездного диспетчера однопутного участка: CP-SAT строит бесконфликтный план, при сбое за секунды даёт 3 варианта с цифрами и объяснением, what-if-песочница, рекомендованный профиль скорости (автоведение). Полная спецификация — `CLAUDE-6.md`, объём MVP — `MVP.md`.

## Запуск в Docker (одной командой)

```bash
cp .env.example .env                 # порты и логины интерфейса (по желанию поменять)
docker compose up -d --build         # http://localhost:8080 — интерфейс, http://localhost:8080/docs — Swagger
docker compose logs -f backend       # логи
docker compose down                  # остановить
```

Два контейнера: `backend` — все сервисы в одном процессе (`python -m app.all`, шина в памяти, CP-SAT в пуле процессов),
`web` — React-интерфейс, собранный в live-режиме, и nginx, который отдаёт статику и проксирует `/api`, `/ws`, `/docs`
на бэкенд. Логины интерфейса встраиваются в сборку фронта (Vite), поэтому после их смены — `docker compose up -d --build web`.

На сервере с доменом: `deploy/nginx/autodispatcher.conf` — nginx хоста с HTTPS перед контейнером `web` (инструкция в файле).

## Запуск без Docker (разработка)

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -e ".[dev]"
.venv/bin/python -m app.all          # http://localhost:8000 — экран, /docs — Swagger
.venv/bin/python -m pytest -q        # smoke-тесты
```

`data/timetable.json` пересобирается командой `.venv/bin/python -m tools.gen_timetable` (около 30 с).

## Демо (MVP.md §6)

1. Открыть http://localhost:8000: поезда едут, поездограмма рисует факт и план, индекс в «Норме».
2. Открыть `/docs` — там все эндпоинты.
3. «Скот на перегоне»: на графике появится красный блок, через ~2 с — 3 карточки. Навести курсор на карточку — «призрак» плана на графике; «Применить» перестраивает план.
4. «Поломка 2003»: нажимать после ~08:55 по часам симуляции, когда 2003 уже в пути. Третьей карточкой появится «Вспомогательный локомотив».
5. What-if: 2003 → 60 км/ч → «Рассчитать»: Δиндекс и изменение прибытия по поездам, текущий план не меняется.
6. Автоведение: 2004 — профиль с накатом и экономией энергии в %.

## Структура

`app/railcore` — доменная логика (модели, времена хода, оценка фиксированного порядка, индекс, скрещения, объяснения, eco-профиль); `app/planner` — CP-SAT, стратегии, варианты, what-if, пул процессов; `app/field` — симулятор поля и сбоев; `app/bus` — шина (in-memory); `app/api` — REST + WS; `web-mvp/index.html` — экран; `tests/test_mvp_smoke.py`.
